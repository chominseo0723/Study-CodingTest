조건2. n의 다음 큰숫자와 n의 2진수로 변환했을 때 1의 갯수 같음
- 2진수 변환 메서드 : String binaryString = Integer.toBinaryString(num);
조건2. n의 다음 큰 숫자는 조건 1,2를 만족하는 가장 작은수

1. n을 2진수로 바꿈
2. split 으로 실패
split -> 맨 뒤의 빈 문자열 제거함

<틀린풀이>
class Solution {
    public int solution(int n) {
        int answer = n + 1;

        String binaryN = Integer.toBinaryString(n);
        String word = "1";

        while (true) {
            String binaryAnswer = Integer.toBinaryString(answer);

            if ((binaryAnswer.split(word).length - 1) == (binaryN.split(word).length - 1)) {
                break;
            }

            answer++;
        }

        return answer;
    }
}
